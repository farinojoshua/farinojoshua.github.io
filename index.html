MLBB Draft Assistant

A draft-pick simulator for Mobile Legends. It follows the real ban-and-pick order and suggests picks, bans and counters per lane, scores each team's draft, and recommends builds and spells against the enemy lineup.

A Python pipeline pulls tier lists, win/pick/ban rates, matchups and synergies every night, so the advice tracks the current meta without anyone touching it. The app itself is plain HTML, CSS and JavaScript with no build step.

About
